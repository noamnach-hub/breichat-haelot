# בריכת האלות

האתר של בריכת האלות, טיפולי וואטסו וצלילים מרפאים במושב טל שחר.

- אתר סטטי: `index.html` ו-`assets/style.css`, בלי שלב בנייה.
- מתפרסם אוטומטית ב-GitHub Pages מענף `main`.
- הוראות תחזוקה ל-Claude Code נמצאות ב-`CLAUDE.md`.
- הקמה ראשונית: `SETUP.md`.

תצוגה מקומית:

```bash
python3 -m http.server 8000
```

ואז לפתוח http://localhost:8000
