# הוספת ליד חדש

הלידים נשמרים בבסיס Airtable בשם **G-Pool.me**, בטבלת הלקוחות. מסך הניהול (g-pool.me/admin) קורא מאותה טבלה, אז ליד שנוסף כאן מופיע שם מיד תחת "לידים ולקוחות".
יהל לא מפתחת: לדבר איתה בעברית פשוטה וקצרה, בלי מונחים טכניים, ולא להראות לה פקודות או שמות שדות.

## 1. לאסוף פרטים
- **טלפון:** חובה. לפחות 9 ספרות. אם חסר, לשאול שאלה אחת קצרה.
- **שם:** רצוי. אם לא נאמר, לשאול פעם אחת. אם אין, להמשיך בלי.
- **הערה:** אופציונלי, למשל מאיפה הגיעה הפנייה או במה מתעניינים. לכתוב רק מה שנאמר, לא להמציא.

## 2. דרך א (מועדפת): הקונקטור של Airtable
אם כלי Airtable זמינים בשיחה:
1. למצוא את הבסיס **G-Pool.me** ואת טבלת הלקוחות (רשימת בסיסים, רשימת טבלאות, ואז `get_table_schema`). בפעם הראשונה בשיחה לבדוק את שמות השדות בפועל: טלפון, שם, סטטוס, מקור, הערות.
2. **לבדוק כפילות:** לחפש רשומה עם אותו טלפון (להשוות ספרות בלבד, בלי מקפים ורווחים). אם קיימת, לא ליצור חדשה: לספר מי רשום עם הטלפון הזה, ולשאול אם להוסיף לו הערה.
3. **ליצור רשומה** עם:
   - טלפון: ספרות בלבד, כמו שאר הרשומות בטבלה (למשל `0521234567`).
   - שם והערה: כפי שנאמרו.
   - סטטוס: `ליד חדש` (בדיוק הערך שקיים בשדה, לא ערך חדש).
   - מקור: ערך קיים מתאים מהשדה (למשל `טלפון`) אם יש כזה. לא ליצור ערכים חדשים בשדות בחירה.
4. לא לשנות את מבנה הטבלה: לא ליצור שדות או טבלאות.

## 3. דרך ב (גיבוי): השרת של מסך הניהול
אם אין קונקטור Airtable בשיחה, להוסיף דרך השרת `https://breichat-haelot-backend.onrender.com`, באותו אופן שמסך הניהול עושה.
- לבקש את קוד הכניסה (4 ספרות) של מסך הניהול. **אסור לשמור את הקוד** בשום קובץ, בזיכרון או ב-commit (הריפו ציבורי).
- אם התשובה הראשונה איטית, השרת מתעורר. לחכות עד דקה ולנסות שוב פעם אחת.

```bash
API=https://breichat-haelot-backend.onrender.com
TOKEN=$(curl -sS -m 90 -X POST "$API/api/admin/login" -H 'Content-Type: application/json' \
  -d "{\"pin\":\"<הקוד>\"}" | python3 -c 'import sys,json;print(json.load(sys.stdin).get("token",""))')
curl -sS -m 60 -X POST "$API/api/admin/clients" -H 'Content-Type: application/json' \
  -H "Authorization: Bearer $TOKEN" -d '{"phone":"<טלפון>"}'          # מחזיר {"client":{"id":...}}
curl -sS -m 60 -X PATCH "$API/api/admin/clients/<id>" -H 'Content-Type: application/json' \
  -H "Authorization: Bearer $TOKEN" -d '{"name":"<שם>","notes":"<הערה>"}'
```
- לבנות JSON עם `json.dumps(..., ensure_ascii=False)` כדי שעברית ומרכאות לא ישברו אותו.
- **401** בכניסה: קוד שגוי. לבקש שוב, לא לנסות שוב ושוב.
- **409** ביצירה: הטלפון כבר קיים. השרת מחזיר את הרשומה ב-`client`.
- **403 ב-CONNECT / שגיאת רשת:** אין גישה מהסביבה הזו. לומר במשפט אחד שאפשר להוסיף את הליד במסך הניהול, בלשונית "לידים ולקוחות".

## 4. לדווח
במשפט אחד או שניים: מי נוסף ועם איזה טלפון, ושאפשר לראות אותו במסך הניהול בלשונית "לידים ולקוחות" בסטטוס "ליד חדש".
