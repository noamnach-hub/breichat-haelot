# הוספת ליד חדש למערכת הניהול

הכלי מוסיף ליד לרשימת "לידים ולקוחות" במסך הניהול (g-pool.me/admin), דרך אותו שרת שמסך הניהול משתמש בו.
יהל לא מפתחת: לדבר איתה בעברית פשוטה וקצרה, בלי מונחים טכניים, ולא להראות לה פקודות.

## 1. לאסוף פרטים
- **טלפון:** חובה. לפחות 9 ספרות. אם חסר, לשאול שאלה אחת קצרה.
- **שם:** רצוי. אם לא נאמר, לשאול פעם אחת. אם אין, להמשיך בלי.
- **הערה:** אופציונלי, למשל מאיפה הגיעה הפנייה או במה הם מתעניינים. לכתוב רק מה שיהל אמרה, לא להמציא.

## 2. קוד הכניסה
- לבקש מיהל את קוד הכניסה (4 ספרות) של מסך הניהול, באותה שיחה.
- **אסור לשמור את הקוד** בשום קובץ, בזיכרון, ב-commit או בהודעה אחרת. הריפו הזה ציבורי. משתמשים בו רק לבקשה הנוכחית.
- אם כבר נכנסת בשיחה הזו והטוקן עדיין עובד, אין צורך לבקש שוב.

## 3. להוסיף את הליד
השרת: `https://breichat-haelot-backend.onrender.com`. אם התשובה הראשונה איטית, זה בגלל שהשרת מתעורר. לחכות עד דקה ולנסות שוב פעם אחת.

```bash
API=https://breichat-haelot-backend.onrender.com
# כניסה: מחזיר token
TOKEN=$(curl -sS -m 90 -X POST "$API/api/admin/login" -H 'Content-Type: application/json' \
  -d "{\"pin\":\"<הקוד>\"}" | python3 -c 'import sys,json;print(json.load(sys.stdin).get("token",""))')

# יצירת הליד לפי טלפון (ספרות בלבד, למשל 0521234567)
curl -sS -m 60 -X POST "$API/api/admin/clients" -H 'Content-Type: application/json' \
  -H "Authorization: Bearer $TOKEN" -d '{"phone":"<טלפון>"}'
# התשובה: {"client":{"id":"...", ...}}

# הוספת שם והערה לליד שנוצר
curl -sS -m 60 -X PATCH "$API/api/admin/clients/<id>" -H 'Content-Type: application/json' \
  -H "Authorization: Bearer $TOKEN" -d '{"name":"<שם>","notes":"<הערה>"}'
```

- לבנות את ה-JSON עם `python3 -c 'import json; print(json.dumps({...}, ensure_ascii=False))'` כדי ששמות בעברית ומרכאות לא ישברו אותו.
- **401** בכניסה: הקוד שגוי. לבקש מיהל שוב. אחרי כמה ניסיונות שגויים השרת עלול לנעול זמנית, אז לא לנסות שוב ושוב.
- **409** ביצירה: כבר יש איש קשר עם הטלפון הזה. השרת מחזיר אותו ב-`client`. לספר ליהל את השם שכבר רשום, ולשאול אם לעדכן לו הערה.
- **שגיאת רשת / proxy (403 ב-CONNECT):** הסביבה לא מאפשרת גישה לשרת. לומר ליהל במשפט אחד שאין גישה מכאן, ושאפשר להוסיף את הליד במסך הניהול, בלשונית "לידים ולקוחות". לא לנסות לעקוף.

## 4. לדווח
במשפט אחד או שניים: מי נוסף, עם איזה טלפון, ושאפשר לראות אותו במסך הניהול בלשונית "לידים ולקוחות" בסטטוס "ליד חדש".
